# ict-251-activity-3.1# Nikiwe Mwale - Personal Portfolio Website

## 1. Project Description

This project is a personal portfolio website created by Nikiwe Taonga Mwale, a Bachelor of Science in Computer Science student.

The website introduces me, presents my hobbies and learning goals, displays my photographs, and provides information about the skills I am developing in Web Technologies.

The website uses a dark-blue-and-silver colour theme and includes interactive features to improve the visitor's experience.

## 2. Project Objectives

The objectives of this project are to:

- Introduce myself and my interests.
- Present my hobbies and learning plan.
- Display photographs and personal media.
- Demonstrate my understanding of HTML, CSS, and JavaScript.
- Practise creating interactive and responsive web pages.
- Apply basic form validation using JavaScript.

## 3. Technologies Used

### HTML5
Used to structure the website and organise its content.

### CSS3
Used to style the website, create layouts, and apply the dark-blue-and-silver theme.

### JavaScript
Used to add interactive features, including the theme switch, photo gallery navigation, and contact form validation.

## 4. Website Features

The website includes:

- Home section
- About Me section
- Hobbies section
- Learning Plan section
- Projects section
- Skills section
- Photo Gallery
- Video section
- Audio section
- Contact Form

Interactive features include:

- Dark and light theme switching
- Previous and Next buttons for browsing photographs
- Contact form validation
- Responsive layouts for different screen sizes

## 6. How to Run the Website

1. Download or clone the project files.
2. Open the project folder in Visual Studio Code.
3. Make sure the HTML, CSS, JavaScript, image, video, and audio files are present.
4. Open index.html using the Live Server extension.
5. View the website in your web browser.

## 7. Contact Form

The contact form demonstrates client-side validation.

It checks whether the visitor has entered a name, a validly formatted email address, and a message.

The form is a demonstration only. It does not send messages to an email address or store submissions on a server.
